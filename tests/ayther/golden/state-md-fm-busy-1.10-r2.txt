state-md-fm-busy-1.10-r2-<layout>.sparse: savestates REALES de un binario
anterior a #118, para check-state-atim-compat (#121).

Hay uno por layout porque el tag AYSS lleva un id de layout (sizeof de void*,
Z80_Regs, m68ki_cpu_core y cart_hw_t) y Windows x64 (LLP64) y Linux/macOS (LP64)
no coinciden: un estado de la otra plataforma se rechaza, como debe, y el
harness elige el que tiene el layout de este core.

  contenido    : blob de 1.036.288 bytes en formato disperso AYSP (solo las zonas
                 no nulas); tag AYSS y bloque AINC presentes, bloque ATIM ausente.
                 ROM sintetico de FM con el 68000 libre, 60 frames, retro_serialize.
  como         : .build/state_atim_compat --dump-sparse <binario de r2> <archivo>

  -win64.sparse
    generado por : genesis_plus_gx_libretro_ayther_x64.dll del release

  -lp64.sparse

  para que     : probar que un estado guardado por un release ANTERIOR a #118
